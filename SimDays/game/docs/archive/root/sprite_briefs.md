# Sprite Generation Briefs

Instructions for AI image generation of character sprites.  
Zoe sprites already exist — this covers the next two needed characters.

**Universal technical requirements:**
- Transparent background PNG
- Full body, standing, facing slightly toward viewer (3/4 angle or straight-on)
- Anime-realistic hybrid style — clean lines, slightly stylized but not chibi. Persona 5 / Coffee Talk aesthetic
- Portrait proportions ~760×1040 px
- Soft neutral lighting (reads on any background)
- Expression changes = face/head swap only, body pose stays the same per outfit

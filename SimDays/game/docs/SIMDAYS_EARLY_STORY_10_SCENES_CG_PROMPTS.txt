SIMDAYS — EARLY STORY SPINE
10 SCENES / FULL CG PROMPT PACK
Target visual language based on the supplied city reference
============================================================

PURPOSE
-------

This pack is designed as an EARLY-GAME visual/story spine rather than a collection
of late-relationship scenes. It starts with MC arriving in the city, establishes
Marcus, Zoe, Nora, Eli and Rena in their actual environments, begins NPC-to-NPC
world overlap, then moves Zoe only as far as the FIRST credible romantic
breakpoints.

The final order is intentionally:

1. Moving Day / Marcus
2. First Morning / Marcus's city
3. Beach Sketchbook / first Zoe
4. Quiet Hour at Grounds / first Nora
5. The Hub / first Eli (conditional IT route)
6. Eleven / first Rena (conditional Culinary route)
7. Wednesday at Grounds / Zoe callback + Nora world overlap
8. Static After Ten / first small group night
9. The Moment That Didn't Happen / Zoe romantic awareness
10. Back to the Beach / interested -> possible dating

This means the story does NOT begin by generating late commitment/love scenes.
The player first has to inhabit the city and build believable history.

============================================================
VISUAL STYLE TARGET
============================================================

The supplied reference image points toward a much cleaner and more coherent
direction than some of the previous CGs.

TARGET LOOK:

- polished 2D anime / visual-novel environmental illustration
- precise architectural perspective
- clean, fine, controlled linework
- bright believable skies and strong environmental readability
- detailed city backgrounds without photorealistic texture
- lush foliage with simplified painterly grouping
- rich but balanced blue/green/neutral palette
- hand-painted cel-style shading
- soft atmospheric perspective
- characters integrated into the environment instead of pasted on top
- matte skin and clothing
- broad natural clothing shadows
- restrained highlights
- low-to-medium character contrast
- candid compositions

DO NOT TARGET:

- photorealism
- pseudo-3D rendering
- glossy AI-looking clothes
- over-sharpened fabric folds
- plastic skin
- giant cinematic rim lights
- neon cyberpunk lighting
- orange/teal grading
- fashion photography
- characters posing at the camera
- over-detailed pores
- exaggerated bloom
- every scene looking like a romance poster

IMPORTANT:
Use the city reference for RENDERING LANGUAGE and COLOR/DETAIL BALANCE.
Do NOT copy its exact buildings, street layout, signage or geography.

============================================================
DO CURRENT ASSETS SUFFICE?
============================================================

SHORT ANSWER:

CHARACTER IDENTITY REFERENCES — probably yes, if the current established
reference images for Marcus, Zoe, Nora, Eli, Rena and MC are still consistent.

ENVIRONMENT STYLE REFERENCES — no. I would NOT generate this entire pack before
creating a small set of new location anchors in the new style.

The problem is not that every old location becomes unusable as a layout
reference. The problem is STYLE CONSISTENCY. If we feed old mixed-style
backgrounds into 70+ new CGs, the generation will keep drifting.

GENERATE THESE REUSABLE LOCATION ANCHORS FIRST:

A. Downtown / neighborhood — bright day
B. Downtown / neighborhood — blue-hour evening
C. Apartment exterior + hallway
D. Grounds Café — exterior + interior
E. Static — exterior night + interior
F. Beach — late afternoon + night
G. City park / basketball court — morning/day
H. The Hub — main dev floor
I. Eleven — professional kitchen before/after service

These are not story CGs. They are clean environmental anchors used repeatedly as
composition/style references.

OUTFIT REFERENCES NEEDED BEFORE MASS GENERATION:

1. Marcus — everyday casual + running + Static work look
2. Zoe — everyday city/beach outfit
3. Nora — Grounds uniform + one off-duty casual look
4. Eli — canonical Hub/work outfit
5. Rena — Eleven chef uniform
6. MC — one canonical generic early-game outfit/back silhouette if MC body design
   is already fixed

If these exact outfits already exist in clean reference sheets, DO NOT redesign
them merely because we are changing rendering style. Use them as identity /
wardrobe references and change only how the final CG is rendered.

I would create the location anchors FIRST, then generate the scene CGs below.

====================================================================

Early game, Day 1. Canonical social opening. Marcus is the first person who makes the city feel inhabited.

STORY / DIRECTING
MC arrives at the apartment building with boxes and immediately has a mundane problem with the apartment door/lock. Marcus, the neighbor, appears and helps without treating it like a dramatic rescue. The scene establishes his confidence, easy social rhythm and tendency to act as if friendship is already underway. He later brings chili / food and lightly invites MC into the local social world. The player's arrival-intent choice is remembered but does not create a quest. Branch at the end: accept Marcus's casual invitation to stop by Static soon, or say not tonight. No penalty; both routes converge into the same early friendship.
